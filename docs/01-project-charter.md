# ขอบเขตโครงการ — ทดลองปลูกใบงาเกาหลีด้วย AI และ IoT

**ฉบับ:** 0.4 | **วันที่:** 5 พฤศจิกายน 2569 | **สถานะ:** ร่างแผน ยังไม่ได้ติดตั้งจริง

## 1. เป้าหมาย

ทดสอบว่า AI สามารถนำข้อมูลสภาพแวดล้อม ภาพถ่าย และประวัติการดูแลมาช่วย **ให้คำแนะนำที่มีเหตุผล ตรวจสอบย้อนกลับได้** สำหรับการปลูกใบงาเกาหลี (Kkaennip / Perilla frutescens) กลางแจ้งในประเทศไทยหรือไม่ โดยยังไม่ให้ AI ควบคุมอุปกรณ์เองในช่วงแรก

## 2. ข้อกำหนดที่ตกลงแล้ว

| หัวข้อ | แนวทาง |
|---|---|
| พื้นที่ | สนามหญ้าหรือพื้นดินกลางแจ้ง ได้แดดเกือบตลอดวัน |
| ขนาดโครงสแลน | 3 × 2 เมตร ต้องตรวจสอบพื้นที่จริงและทางเดิน |
| การปลูก | 12 กระถาง แบ่งกลุ่ม A 6 กระถาง / B 6 กระถาง |
| แสง | สแลนพรางแสง 50% แบบถอด/ม้วนได้ ด้านข้างเปิดโล่ง |
| น้ำ | รดน้ำด้วยมือทุกต้น และบันทึกปริมาณจริง |
| เซนเซอร์ | ESP32, ความชื้นดิน 4 จุด, อุณหภูมิ/ความชื้นอากาศ 1 จุด, แสง 2 จุด |
| ภาพพืช | ถ่ายด้วยมือถือในมุมและช่วงเวลาที่สม่ำเสมอ |
| ระบบข้อมูล | MQTT → InfluxDB → Grafana บน Home Lab เดิม |
| AI | วิเคราะห์และเสนอคำแนะนำเป็นรอบ ไม่สั่งปั๊มน้ำหรือสแลนอัตโนมัติ |

## 3. ขอบเขตงาน

**ระยะเตรียมการ / สัปดาห์ 0–2:** สำรวจแดดและน้ำขัง ตรวจสัญญาณ Wi-Fi/ไฟฟ้า เตรียมเมล็ด กระถาง โครงสแลน และทดสอบการเก็บข้อมูล

**ระยะทดลอง / สัปดาห์ 3–6:** เปรียบเทียบกลุ่ม A ที่ใช้แนวทางดูแลมาตรฐานกับกลุ่ม B ที่ใช้คำแนะนำ AI เพื่อช่วยตัดสินใจ **ให้น้ำ** โดยคนอนุมัติทุกครั้ง

**ระยะประเมิน / สัปดาห์ 7–8:** ประเมินอัตรารอด การเติบโต การใช้น้ำ เวลาดูแล และคุณภาพคำแนะนำ หากยังไม่พร้อมเก็บใบให้ขยายระยะติดตาม

**สิ่งที่ยังไม่ทำ:** ปั๊มน้ำอัตโนมัติ มอเตอร์สแลน ระบบจ่ายปุ๋ย กล้องถาวร การวินิจฉัยโรคแบบยืนยันผล และการกล่าวอ้างผลผลิตเชิงพาณิชย์

## 4. ข้อสมมติและข้อจำกัด

- สแลน 50% เป็น **ค่าเริ่มทดลอง** ไม่ใช่สัดส่วนที่พิสูจน์แล้วว่าเหมาะที่สุดในทุกสภาพอากาศ
- ใบงาเกาหลีอาจเข้าสู่ระยะออกดอกตามช่วงแสงและสายพันธุ์ โดยเฉพาะการเริ่มปลูกปลายปี จึงต้องบันทึกวันที่พบตาดอก
- เซนเซอร์แสงหน่วย **ลักซ์ (lux)** ไม่ใช่เครื่องวัด PAR/PPFD จึงไม่ควรนำไปคำนวณปริมาณแสงสำหรับสังเคราะห์แสงรายวันโดยตรง
- จำนวน 6 ต้นต่อกลุ่มเหมาะกับการตรวจสอบความเป็นไปได้เบื้องต้น ไม่พอใช้ยืนยันความเหนือกว่าทางสถิติ
- กลุ่ม A และ B ใช้สแลนร่วมกัน ดังนั้นผลของการเปิดสแลน **ไม่ใช่ผลของ AI เฉพาะกลุ่ม B**

## 5. เกณฑ์ความสำเร็จเบื้องต้น

1. อัตรารอดเมื่อจบสัปดาห์ที่ 6 อย่างน้อย 80% เป็นเป้าหมาย ไม่ใช่การรับประกันผล
2. ข้อมูลเซนเซอร์ครบอย่างน้อย 90% ของช่วงที่ระบบควรทำงาน
3. มีภาพถ่ายแต่ละต้นอย่างน้อย 4 วันต่อสัปดาห์ และมีประวัติให้น้ำพร้อมปริมาณ
4. มีรายงาน AI อย่างน้อยวันละ 1 ครั้งในระยะทดลอง พร้อมหลักฐานและการตัดสินใจของคน
5. เปรียบเทียบ A/B ได้ทั้งอัตรารอด จำนวนใบ ขนาดใบ ความสูง น้ำหนักผลผลิต (หากพร้อมเก็บ) ปริมาณน้ำ และเวลาทำงาน
6. ไม่เกิดอันตรายจากโครงสแลนหรือระบบไฟฟ้า

## 6. ความเสี่ยงและแนวทางป้องกัน

| ความเสี่ยง | แนวทาง |
|---|---|
| ฝนตกหนัก น้ำขัง | ยกกระถาง 10–15 ซม. ให้รูระบายน้ำเปิดโล่ง สำรวจทางน้ำไหล |
| ลมพัดโครงเสียหาย | ค้ำยันและยึดสมอบกตามดินจริง ใช้สแลนถอดได้ก่อนพายุ |
| แดดบ่ายแรง ใบเหี่ยว | บังแดดช่วงร้อนและตรวจความชื้นก่อนสรุปว่าขาดน้ำ |
| กลุ่มทดลองได้รับแสงต่างกัน | สลับตำแหน่ง A/B และใช้สแลนร่วมกัน |
| AI แนะนำผิด | แสดงความไม่แน่นอนพร้อมหลักฐาน คนอนุมัติทุกครั้ง |
| เซนเซอร์ความชื้นคลาดเคลื่อน | สอบเทียบกับดินจริง ตรวจซ้ำด้วยมือ/น้ำหนักกระถาง |
| AI PC ไม่เปิดตลอดเวลา | เก็บข้อมูลไว้บน Home Lab และให้ AI ประมวลผลย้อนหลังได้ |

## 7. ข้อมูลอ้างอิง

- [ฐานข้อมูลพืชของมหาวิทยาลัยแห่งรัฐนอร์ทแคโรไลนา — Perilla frutescens](https://plants.ces.ncsu.edu/plants/perilla-frutescens/common-name/perilla/) อ้างอิงลักษณะการปลูกในแดดเต็มวันหรือร่มบางส่วนและดินระบายน้ำดี
- ค่าการบังแดดและแนวทางดูแลในโครงการนี้เป็น **ข้อสมมติที่ต้องตรวจสอบจากพื้นที่จริง** ไม่ใช่คำแนะนำมาตรฐานที่ใช้ได้ทุกบ้าน
