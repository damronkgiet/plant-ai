# เปรียบเทียบการเชื่อมต่อเซนเซอร์ — Smart Perilla Farm

สถานะ: บันทึกทางเลือกเพื่อใช้ตัดสินใจหลังทดลองต้นแบบ (17 พ.ย. 2026)

## เป้าหมาย
แปลงทดลอง 12 กระถาง พื้นที่ประมาณ 3 × 2 เมตร เริ่มด้วย ESP32 1 ตัว + เซนเซอร์ความชื้นดินแบบ Capacitive 1 ตัว ส่ง Wi-Fi/MQTT เข้า Home Lab → InfluxDB → Grafana ทุกประมาณ 5 นาที

## ตัวเลือก

| แบบ | การเชื่อมต่อ | พลังงานที่จุดเซนเซอร์ | ข้อดี | ข้อจำกัด |
| --- | --- | --- | --- | --- |
| Analog มีสาย + ESP32 กลาง | สาย VCC/GND/Analog ต่อแต่ละเซนเซอร์ | จาก ESP32 | ถูก เริ่มง่าย ควบคุมเฟิร์มแวร์เอง | ต้องลากสายทุกหัววัด; สาย Analog ยาวอาจรบกวน |
| ESP32 หลายจุด + Wi-Fi | สายสั้นถึง ESP32 ประจำโซน; Wi-Fi ไป Home Lab | ต้องจ่ายไฟแต่ละโซน | ยืดหยุ่น ไม่ต้องลากสัญญาณไกล | หลายบอร์ด/หลายจุดจ่ายไฟ |
| BLE soil sensor สำเร็จรูป | BLE → BLE gateway/ESP32 → MQTT | แบตเตอรี่ในเซนเซอร์ | ลดสาย มีรุ่นสำเร็จรูป | ต้องเช็กโปรโตคอล ความเข้ากันได้และอายุแบต |
| Zigbee soil sensor สำเร็จรูป | Zigbee → coordinator → Zigbee2MQTT | แบตเตอรี่ในเซนเซอร์ | เพิ่มอุปกรณ์ได้สะดวก | ต้องมี coordinator; เช็กรุ่นที่รองรับและความทนกลางแจ้ง |
| LoRa sensor node | LoRa → gateway | แบตเตอรี่/โซลาร์ | เหมาะระยะไกล | เกินความจำเป็นสำหรับแปลงเล็ก; ต้นทุน/ความซับซ้อนเพิ่ม |

## ต้องบัดกรีไหม?
- **ต้นแบบไม่จำเป็นต้องบัดกรี** หากเลือก ESP32 DevKit ที่มีขา header ติดมาแล้ว ใช้ breadboard และสาย jumper
- เซนเซอร์ DFRobot SEN0193 ใช้ขั้ว Gravity 3-pin; ตรวจว่ามีสาย Gravity มาในชุดหรือไม่ และอาจต้องใช้สายแปลงเป็นหัว Dupont เพื่อเข้ากับ breadboard/ESP32
- ต่อเซนเซอร์ Analog: VCC → 3.3V, GND → GND, AOUT → ADC1 (เช่น GPIO34 ของ ESP32-WROOM-32 รุ่นคลาสสิก); ตรวจ pinout รุ่นที่ซื้อจริง ห้ามให้สัญญาณเกิน 3.3V
- สำหรับติดตั้งกลางแจ้งถาวร **ไม่แนะนำ breadboard หรือ jumper เปลือย**; ใช้ขั้วต่อยึดแน่น สายและกล่องกันน้ำพร้อม cable gland อาจบัดกรี/เข้าหัว/ใช้ terminal block ตามชิ้นส่วนที่เลือก

## ข้อเสนอและเกณฑ์ตัดสินใจ
1. ทำ POC แบบมีสาย 1 เซนเซอร์บนโต๊ะก่อน ให้ MQTT/Grafana ทำงาน
2. ทดสอบการใช้ไฟและความเสถียรของ Wi-Fi
3. รอภาพพื้นที่จริงก่อนกำหนดจุดติดตั้งและระบบไฟ (เส้นทางราว 10 ม.: พื้นปูน 5 ม. + ดิน 5 ม.)
4. ก่อนซื้อเซนเซอร์ไร้สาย ตรวจรุ่นจริงว่ารองรับ Zigbee2MQTT/BLE gateway, วัดความชื้น **ดิน**, ระดับกันน้ำ, แบตเตอรี่ และความถี่รายงาน
5. ตัดสินใจระหว่าง ESP32 กลางแบบมีสายกับเซนเซอร์ไร้สายหลังรู้ตำแหน่งกระถางและต้นทุนรวม

ข้อควรระวัง: อุปกรณ์ไร้สายยังต้องใช้พลังงาน; การไม่มีสายสัญญาณไม่เท่ากับไม่มีงานดูแลแบตเตอรี่
