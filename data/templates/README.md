# แบบฟอร์มบันทึกข้อมูลโครงการ — คำอธิบายภาษาไทย

ไฟล์ CSV ในโฟลเดอร์นี้เป็น **แบบฟอร์มตั้งต้น** ยังไม่มีผลการวัดจริง

**หมายเหตุ:** ชื่อคอลัมน์ในไฟล์ใช้ภาษาอังกฤษเป็นรหัสทางเทคนิคสำหรับนำเข้าฐานข้อมูลและใช้กับโปรแกรม ส่วนความหมายและคู่มือใช้งานทั้งหมดเป็นภาษาไทย ดังนั้นไม่ควรเปลี่ยนชื่อคอลัมน์โดยไม่ปรับระบบรับข้อมูลไปพร้อมกัน

## 1. ทะเบียนกระถาง

ไฟล์: [plant-registry.csv](plant-registry.csv)

| รหัสคอลัมน์ | ความหมายภาษาไทย |
|---|---|
| pot_id | รหัสกระถาง เช่น A01 หรือ B02 |
| arm | กลุ่มทดลอง A = ดูแลมาตรฐาน, B = ใช้คำแนะนำ AI |
| x_m | พิกัดแนวนอนจากด้านตะวันตกตามผัง หน่วยเมตร |
| y_m | พิกัดแนวตั้งจากด้านใต้ตามผัง หน่วยเมตร |
| seed_variety | พันธุ์หรือชื่อบนซองเมล็ด |
| seed_lot | หมายเลขรุ่น/ชุดเมล็ด ถ้ามี |
| sown_date | วันที่เพาะเมล็ด |
| transplant_date | วันที่ย้ายต้นลงกระถาง |
| pot_volume_l | ปริมาตรกระถาง หน่วยลิตร |
| substrate_batch | รหัสชุดดินหรือวัสดุปลูก |
| notes | หมายเหตุ |

**หลักการ:** รหัสกระถางและพิกัดเป็นค่าตั้งต้นตามผัง 3 × 2 เมตร หากเปลี่ยนผังต้องอัปเดตทะเบียนก่อนติดตั้ง

## 2. บันทึกสุขภาพและการเติบโต

ไฟล์: [daily-observations.csv](daily-observations.csv)

| รหัสคอลัมน์ | ความหมายภาษาไทย |
|---|---|
| date | วันที่ตรวจ (ปี-เดือน-วัน) |
| local_time | เวลาท้องถิ่นประเทศไทย (ชั่วโมง:นาที) |
| pot_id | รหัสกระถาง |
| height_cm | ความสูงต้น หน่วยเซนติเมตร |
| healthy_leaf_count | จำนวนใบที่สมบูรณ์ |
| largest_leaf_length_cm | ความยาวใบที่ใหญ่ที่สุด หน่วยเซนติเมตร |
| largest_leaf_width_cm | ความกว้างใบที่ใหญ่ที่สุด หน่วยเซนติเมตร |
| leaf_stress_0_3 | ระดับอาการผิดปกติของใบ 0 = ปกติ, 1 = เล็กน้อย, 2 = ปานกลาง, 3 = รุนแรง |
| flower_buds_present | พบตาดอกหรือไม่ (จริง/เท็จ) |
| pest_signs | อาการหรือร่องรอยแมลง |
| photo_path | ตำแหน่งไฟล์ภาพ |
| observer | ผู้ตรวจ |
| notes | หมายเหตุ |

**หลักการ:** ถ่ายภาพใกล้เคียงเวลาเดิม ใช้มุมมาตรฐานและไม้บรรทัดเพื่อเทียบขนาด

## 3. บันทึกการรดน้ำและการตัดสินใจ

ไฟล์: [watering-log.csv](watering-log.csv)

| รหัสคอลัมน์ | ความหมายภาษาไทย |
|---|---|
| date | วันที่ทำกิจกรรม |
| local_time | เวลาท้องถิ่นประเทศไทย |
| pot_id | รหัสกระถาง |
| arm | กลุ่มทดลอง A/B |
| water_ml | ปริมาณน้ำที่เติม หน่วยมิลลิลิตร |
| rain_since_last_check | มีฝนตั้งแต่การตรวจครั้งก่อนหรือไม่ |
| soil_manual_check | ผลตรวจดินด้วยมือ |
| ai_recommendation_id | รหัสคำแนะนำ AI ถ้ามี |
| decision_status | ผลการตัดสินใจ เช่น รับ / ปรับ / ไม่รับ / ไม่เกี่ยวข้อง |
| human_action_reason | เหตุผลการดำเนินการของผู้ดูแล |
| minutes_spent | เวลาที่ใช้ทำกิจกรรม หน่วยนาที |
| operator | ผู้ดำเนินการ |

**หลักการ:** ระบุปริมาณน้ำเป็นตัวเลขจริงทุกครั้ง การรดน้ำช่วยต้นฉุกเฉินต้องบันทึกไว้ทั้งกลุ่ม A และ B
